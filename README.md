# First Apartment Budget Comparator

**By Meredith Makowsky – Accounting Major**

## Overview
An interactive Excel tool for comparing first apartment budgets. Calculates total monthly/annual costs, accounting for whether utilities are included or not. Supports up to 3 apartments.

**Key Features**
- Yes/No dropdown for utilities included
- Automatic calculations (rent + utilities + fixed expenses like groceries/transport/internet)
- Total cost comparisons
- Bar chart for monthly costs
- Pie chart for expense breakdown
- Highlights the cheapest option

**Skills Demonstrated**
- **Accounting:** Financial modeling, budgeting, cost analysis
- **Excel:** Advanced formulas (IF, SUM), data validation, conditional formatting, charts
- **AI:** Used Google Gemini/ChatGPT to generate formulas and workbook structure (no coding needed)

**How to Use**
1. Download/open the .xlsx file
2. Enter apartment details in the "Inputs" sheet
3. View automatic results, comparisons, and charts in "Summary & Charts"
